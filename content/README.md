# Content — social posts for the build journey

This folder holds ready-to-post writeups documenting the `security-homelab` build as I
go. Each work session gets its own dated post so I can share progress on LinkedIn and
Twitter/X without rewriting anything.

## Files
- `01-linkedin-dc-and-kali.md` — LinkedIn post covering the DC + Kali milestone.
- `01-twitter-dc-and-kali.md` — the same milestone as a Twitter/X thread.

## How to use
1. Open the file for the milestone.
2. Copy the text (everything under the `---POST---` marker).
3. Paste into LinkedIn / X. Swap in your own screenshots where noted.

## Notes
- These contain **no secrets** — safe to commit and share.
- Written in my own voice, first person. Tweak wording so it sounds like me.
- Add a new numbered pair each session (`02-...`, `03-...`).
